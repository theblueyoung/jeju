# Visit Jeju

A tourism website showcasing Jeju, a beautiful island in South Korea. 

## Description

This website is built mobile-first with only html and css and no javascript.

### HTML
There are 5 web pages in total. I have kept the html simple and stupid: common elements such as header, footer are repeated in each file and not extracted into templates and loaded with javascript. 

### CSS
I have used [Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) and media queries to make the website mobile-responsive. `style.css` contains all styling to all pages. To make the code slightly easier to navigate, I have grouped the code according by pages and by common elements (like header, hero images).
